# 15: Счётчик отложений отдыха сбрасывается при перезапуске приложения

**What to build:** Лимит «не больше двух отложений подряд» должен переживать перезапуск приложения. Сейчас после перезапуска показанное предложение отдыха получает полный лимит заново, поэтому откладывать можно бесконечно, если между отложениями закрывать и открывать приложение.

**Blocked by:** None (can start immediately).

**Status:** needs-triage

- [ ] Счётчик отложений сохраняется в документе рабочего дня и восстанавливается вместе с предложенным отдыхом.
- [ ] После перезапуска с двумя израсходованными отложениями доступны только «Начать отдых» и «Пропустить».
- [ ] Счётчик по-прежнему сбрасывается при начале, пропуске и завершении отдыха.
- [ ] Тест ядра: два отложения, перезапуск через документ, предложение возвращается без доступного отложения.

## Comments

- Найдено при сквозной проверке на эмуляторе `wrb_api36` (тикет 14). Шаги: день начат в 09:20; предложение отдыха в 10:00; «Отложить на 5 минут»; перезапуск приложения в 10:12 (предложение должно вернуться в 10:11) — экран показывает «Можно отложить ещё: 2», хотя одно отложение уже было сделано.
- Повторная проверка в одном запуске: отложение уменьшает счётчик до 1, следующее — до 0; но любой перезапуск возвращает полный лимит.
- Ожидание: `postponesUsed` уже пишется в документ (`core/lib/src/persisted_document.dart`), значит восстановление предложения отдыха пересоздаёт его без переноса счётчика. Проверить `WorkDayEngine.restore` и путь восстановления предложения.
