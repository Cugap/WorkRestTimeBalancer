# 16: Ручной проход MVP на реальных устройствах (включая iOS)

**What to build:** Пройти оставшуюся часть сквозного чек-листа на реальных устройствах: iOS целиком (сборка требует macOS с Xcode), ручной ввод недопустимых значений в настройках, экспорт и импорт через системные диалоги файлов, значок и меню трея Windows, отключение автозапуска из интерфейса.

**Blocked by:** 15 — Счётчик отложений отдыха сбрасывается при перезапуске приложения; 14 — Сквозная проверка MVP на трёх платформах.

**Status:** needs-triage

- [ ] iOS: сборка на macOS, локальные уведомления при свёрнутом приложении, нажатие открывает экран отдыха, отключение звука и напоминаний, отсутствие напоминаний после паузы и конца дня.
- [ ] iOS: после возврата в приложение состояние соответствует реально прошедшему времени; в пределах системного лимита запланированных уведомлений (около 64) ничего не теряется.
- [ ] Настройки: недопустимые значения отклоняются с сообщением, прежнее значение сохраняется, «По умолчанию» возвращает исходные значения.
- [ ] Экспорт создаёт JSON-файл через системный диалог; импорт заменяет настройки и журнал после подтверждения; повреждённый файл отклоняется без потери данных.
- [ ] Windows: значок в трее виден, «Открыть приложение» восстанавливает окно, «Завершить рабочий день» завершает день, при выключенном трее закрытие окна завершает приложение.
- [ ] Windows: включение автозапуска из настроек создаёт запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, выключение удаляет её; после перезагрузки системы приложение стартует.
