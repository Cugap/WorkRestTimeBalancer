# 09: Экспорт и импорт данных

**What to build:** Настройки и журнал событий экспортируются в один версионированный JSON-файл и импортируются на другом устройстве. Импорт спрашивает подтверждение, заменяет настройки и журнал и не трогает идущий рабочий день. Файл несовместимой версии или повреждённый файл даёт понятную ошибку и не меняет текущие данные.

**Blocked by:** 08 — Локальное хранение и восстановление после перезапуска.

**Status:** ready-for-agent

- [ ] Экспорт создаёт JSON-файл с версией формата, настройками и журналом событий.
- [ ] Импорт валидного файла после подтверждения заменяет настройки и журнал.
- [ ] Импорт не меняет идущий рабочий день, текущий отдых и показанное предложение.
- [ ] Файл другой версии или повреждённый файл отклоняется с сообщением, текущие данные не меняются.
- [ ] Экспорт и импорт фиксируются в журнале событий.
- [ ] Тесты ядра покрывают сериализацию, проверку версии и отказ при повреждённом файле.
