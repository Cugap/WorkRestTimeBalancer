# 04: Экран отдыха и упражнения для короткого отдыха

**What to build:** Предложенный отдых открывает полноэкранный экран внутри приложения с таймером и одним упражнением. Упражнение берётся из локального набора из 25–40 упражнений с категориями «глаза», «руки», «тело» по кругу, без повтора предыдущего; когда круг заканчивается, начинается новый. Отдых можно закончить досрочно. Если закрыть экран, отдых не прерывается, а повторное открытие возвращает к нему.

**Blocked by:** 02 — Короткий отдых по фиксированному ритму.

**Status:** ready-for-agent

- [x] Набор из 25–40 упражнений поставляется вместе с приложением и доступен офлайн; у каждого упражнения есть название, описание, длительность и категория.
- [x] Короткий отдых показывает ровно одно упражнение.
- [x] Упражнения идут по кругу и не повторяют предыдущее; после конца набора круг начинается заново.
- [x] Полноэкранный экран показывает таймер отдыха и кнопку «Закончить сейчас».
- [x] Досрочное завершение отдыха начинает новый интервал работы с этого момента.
- [x] Закрытие экрана не останавливает отдых; повторное открытие возвращает к идущему отдыху.
- [x] Экран отдыха не блокирует другие приложения.
- [x] Тесты ядра покрывают выбор упражнений и досрочное завершение отдыха.

## Comments

- Набор: `core/lib/src/exercise_catalog.dart` — 30 упражнений (по 10 на глаза, руки и тело) как `const`-список в ядре, то есть они компилируются в приложение и доступны офлайн, без ассетов и сети. Категории в наборе чередуются, чтобы подряд идущие отдыхи разминали разные части тела. Модель — `Exercise` (`id`, название, описание, длительность 20–40 секунд, категория `ExerciseCategory`).
- Выбор упражнений живёт в ядре: `WorkDayEngine` держит курсор `_nextExerciseIndex` и при `startRest` берёт одно упражнение, сдвигая курсор на единицу по модулю длины набора. Поэтому упражнение не повторяет предыдущее, после конца набора круг начинается заново, а пропущенный отдых курсор не расходует. Набор можно подменить через параметр `catalog` — тесты набора не зависят от поставляемого списка.
- Снимок получил `exercises` (упражнения текущего отдыха, вне отдыха пусто) и `lastRestFinished` (последнее завершение отдыха за текущий рабочий день). Экран ничего не вычисляет: таймер, длительность и упражнение приходят из `snapshot(now)`.
- Команда `finishRest(now)` завершает идущий отдых: новый интервал работы начинается с этого момента, следующий отдых планируется через `now + shortRestInterval`. Отдых вне фазы `resting` отклоняется новой причиной `RejectionReason.restNotInProgress`. В фазе отдыха доступны `finishRest` и `finish`.
- Журнал: `WorkDayEvent.restFinished` расширен необязательными `restFinishReason` (`natural`, `early`, `workDayEnded`) и `plannedDuration` / `actualDuration`; старые проверки журнала обновлены с этими полями без изменения смысла. Естественный конец отдыха, досрочный конец и прерывание завершением рабочего дня различаются причиной. Досрочное завершение за концом рабочего окна не начинает работу: день закрывается по концу окна, как и при естественном конце.
- Счётчик отложений сбрасывать пока нечего: отложение — тикет 03, в `mvp` его ещё нет. `finishRest` — то место, где сброс появится вместе с самим счётчиком (спецификация требует сброса при начале, пропуске и завершении отдыха).
- Экран: `app/lib/src/rest_screen.dart` — полноэкранный `Scaffold` с таймером отдыха, одним упражнением (название, описание, категория и длительность) и кнопкой «Закончить сейчас». В фазе предложения экран показывает «Начать отдых» / «Пропустить». Экран не блокирует другие приложения: нет ни overlay-окон, ни accessibility-сервисов, ни topmost-режима (ADR-0004). Закрытие экрана ничего не останавливает — таймером владеет ядро; когда отдых заканчивается, экран сам возвращается к рабочему дню.
- Главный экран в фазах `restOffered` и `resting` показывает кнопку «Экран отдыха»; повторное открытие возвращает к идущему отдыху и тому же упражнению.
- Тесты: `core/test/exercises_test.dart` (состав набора, одно упражнение на коротком отдыхе, круг без повтора, новый круг после конца набора, пропуск не расходует упражнение), группа «досрочное завершение отдыха» в `core/test/short_rest_test.dart` (новый интервал, журнал с причиной и длительностями, отказ, конец окна, завершение дня во время отдыха) и сценарий «досрочное завершение отдыха продолжает ритм» в `core/test/work_day_scenario_test.dart`. UI: `app/test/rest_screen_test.dart` проверяет экран по ключам и снимку ядра (одно упражнение, таймер, досрочное завершение, закрытие и повторное открытие); `FakeClock` вынесен в `app/test/fake_clock.dart`.
- Проверено: `dart analyze` (без замечаний), `dart test` (62 теста), `flutter analyze` (без замечаний), `flutter test` (9 тестов).
