# 04: Экран отдыха и упражнения для короткого отдыха

**What to build:** Предложенный отдых открывает полноэкранный экран внутри приложения с таймером и одним упражнением. Упражнение берётся из локального набора из 25–40 упражнений с категориями «глаза», «руки», «тело» по кругу, без повтора предыдущего; когда круг заканчивается, начинается новый. Отдых можно закончить досрочно. Если закрыть экран, отдых не прерывается, а повторное открытие возвращает к нему.

**Blocked by:** 02 — Короткий отдых по фиксированному ритму.

**Status:** ready-for-agent

- [ ] Набор из 25–40 упражнений поставляется вместе с приложением и доступен офлайн; у каждого упражнения есть название, описание, длительность и категория.
- [ ] Короткий отдых показывает ровно одно упражнение.
- [ ] Упражнения идут по кругу и не повторяют предыдущее; после конца набора круг начинается заново.
- [ ] Полноэкранный экран показывает таймер отдыха и кнопку «Закончить сейчас».
- [ ] Досрочное завершение отдыха начинает новый интервал работы с этого момента.
- [ ] Закрытие экрана не останавливает отдых; повторное открытие возвращает к идущему отдыху.
- [ ] Экран отдыха не блокирует другие приложения.
- [ ] Тесты ядра покрывают выбор упражнений и досрочное завершение отдыха.
