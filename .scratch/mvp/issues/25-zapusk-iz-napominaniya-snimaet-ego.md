# 25: Запуск из напоминания снимает его при старте

**What to build:** Если приложение запущено напоминанием (нажатием или полноэкранным намерением на заблокированном экране), это уведомление не исчезает при инициализации: человек видит его и предложение отдыха, а уведомление снимается, когда он отвечает на отдых.

**Status:** done

- [x] При старте из напоминания сохраняется только уведомление, которым запустили приложение: унаследованная раскладка и остальные показанные напоминания снимаются. — `RestNotifications.initialize` читает `launchedReminderId` и передаёт `clearPreviousRun(keepId: ...)`; платформа оставляет показанным только этот номер.
- [x] Ответ на отдых снимает и запустившее уведомление, даже если после догона у предложения оказался другой номер: адаптер запоминает номер запустившего уведомления и снимает его вместе с номером текущего предложения.
- [x] Обычный запуск по-прежнему снимает показанные устаревшие уведомления прошлого запуска.
- [x] Покрыто тестами: `app/test/rest_notifications_test.dart` — «запуск из напоминания не снимает показанное уведомление», «обычный запуск снимает унаследованную раскладку», «ответ снимает и напоминание, которым запустили приложение», «совпадающий номер снимается один раз».

## Comments

- Найдено на повторной проверке тикета 16 после переустановки: приложение, запущенное полноэкранным намерением напоминания, при инициализации вызывало `cancelAll()` и снимало в том числе только что показанное уведомление. Экран отдыха открывался, а на замке уведомления не оставалось.
- Исправление: `clearPreviousRun(keepId:)` отделён от инициализации плагина. `RestNotifications.initialize` просит у платформы номер уведомления, которым запустили приложение, и при старте сохраняет только его, а остальные показанные напоминания и унаследованную раскладку снимает. Номер запустившего уведомления запоминается в адаптере: ответ на отдых снимает и его, даже если после догона у предложения другой номер.
- Открытие экрана отдыха по-прежнему опирается на `launchedFromNotification`, а не на номер: на платформах, где номер не отдаётся, запуск всё равно распознаётся.
- Исключение действует для Android: на Windows напоминания — toast'ы, и они исчезают сами.
