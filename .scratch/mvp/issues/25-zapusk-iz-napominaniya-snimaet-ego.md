# 25: Запуск из напоминания снимает его при старте

**What to build:** Если приложение запущено напоминанием (нажатием или полноэкранным намерением на заблокированном экране), это уведомление не исчезает при инициализации: человек видит его и предложение отдыха, а уведомление снимается, когда он отвечает на отдых.

**Status:** done

- [x] При старте из напоминания снимается только унаследованное расписание, показанное уведомление остаётся. — `RestNotifications.initialize` читает `launchedFromNotification` и передаёт `clearInherited(keepShown: true)`; на Android платформа отменяет только запланированные напоминания.
- [x] Обычный запуск по-прежнему снимает показанные устаревшие уведомления прошлого запуска.
- [x] Покрыто тестами: `app/test/rest_notifications_test.dart` — «запуск из напоминания не снимает показанное уведомление» и «обычный запуск снимает унаследованное расписание».

## Comments

- Найдено на повторной проверке тикета 16 после переустановки: приложение, запущенное полноэкранным намерением напоминания, при инициализации вызывало `cancelAll()` и снимало в том числе только что показанное уведомление. Экран отдыха открывался, а на замке уведомления не оставалось.
- Исправление: `clearInherited(keepShown:)` отделён от инициализации плагина. `RestNotifications.initialize` спрашивает у платформы, запущено ли приложение напоминанием, и при `true` платформа отменяет только запланированные напоминания. Унаследованные показанные уведомления прошлого запуска при обычном старте по-прежнему снимаются.
- Исключение действует для Android: на Windows напоминания — toast'ы, и они исчезают сами.
