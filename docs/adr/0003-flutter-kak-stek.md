# Flutter как стек для Android, iOS и Windows

- **Status**: accepted

Выбрали Flutter: все три целевые платформы для него официально поддерживаются и тестируются в CI (матрица Flutter 3.47 — Windows 10/11, Android 24–37, iOS 15–27), а один плагин закрывает запланированные уведомления на всех трёх: `flutter_local_notifications` поддерживает Android, iOS и Windows (Toast через C++/WinRT) и умеет Android full-screen intent.

Стоимость установки тулчейна в сравнение сознательно не входила: стек выбирается по качествам, а не по тому, что уже стоит на машине.

## Considered Options

- **Flutter** (выбрано) — единственный вариант, где все три платформы официально поддерживаются и тестируются в CI; лучший инструментарий для UI экрана отдыха; самый зрелый плагин уведомлений. Слабое место — десктопная интеграция (трей, автозапуск) живёт в community-пакетах.
- **.NET MAUI** — лучшая нативная интеграция с Windows (WinUI 3), но мобильный UI и экосистема уведомлений слабее, а iOS всё равно требует Mac с Xcode и платного Apple Developer Program.
- **Kotlin Multiplatform + Compose Multiplatform** — Android, iOS и Desktop (JVM) официально Stable, но Windows здесь — JVM-десктоп с упаковкой через jpackage, а уведомления и трей пишутся под каждую платформу вручную.
- **React Native + react-native-windows** — Windows-ветка всё ещё переезжает с Paper на Fabric/WinAppSDK, для проекта на одного разработчика это лишний риск.

## Consequences

- Для Android нужны Android SDK и JDK 17+, для iOS — Mac с Xcode и аккаунт Apple Developer Program, для Windows — Visual Studio с C++ workload.
- Точные напоминания на Android требуют разрешения на точные будильники: неточные на Android 12+ система сдвигает вплоть до часа.
- На iOS фонового таймера нет — напоминания планируются заранее локальными уведомлениями, а не считаются в фоне (у iOS также есть лимит на число запланированных уведомлений).
- Трей, автозапуск и «поверх всех окон» на Windows — через community-пакеты (`system_tray`, `launch_at_startup`, `window_manager`); это единственное место, где мы зависим от сторонних мейнтейнеров.
- Ядро (ритм, расписание пауз, журнал событий) живёт в отдельном Dart-пакете без импортов Flutter и тестируется без UI.
