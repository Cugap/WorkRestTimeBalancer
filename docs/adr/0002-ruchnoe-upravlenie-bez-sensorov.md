# Отслеживание работы только вручную, без сенсоров активности ОС

Приложение не определяет, работает ли человек, средствами операционной системы: ритм тикает только внутри запущенного рабочего дня, который пользователь сам стартует, ставит на паузу и завершает.

Причина в том, что единого способа узнать активность на трёх целевых платформах нет — на iOS такого API не существует вовсе, а на Windows и Android это отдельный пласт прав, фоновых служб и ложных срабатываний. Авто-пауза по простою остаётся возможным дополнением позже и не ломает модель.
