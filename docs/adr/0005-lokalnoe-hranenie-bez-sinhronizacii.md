# Локальные настройки без синхронизации в MVP

- **Status**: accepted

Настройки и журнал событий живут только на устройстве. Перенос между Windows, Android и iOS — вручную, файлом JSON. Синхронизация требует аккаунтов, сервера и хранения данных о том, как человек работает, а выигрыш в MVP этого не оправдывает.

## Considered Options

- Только локально + экспорт/импорт JSON (выбрано)
- Своя синхронизация через аккаунт и бэкенд
- Синхронизация через стороннее облако (iCloud / Google Drive) без своего бэкенда

## Consequences

- На каждом устройстве своя история; при смене устройства настройки переносятся файлом.
- Добавление синхронизации позже потребует аккаунтов и миграции данных — это осознанная цена за отсутствие бэкенда сейчас.
