# Без жёсткой блокировки других приложений

- **Status**: accepted

Отдых напоминает о себе уведомлением и полноэкранным окном внутри приложения, которое можно отложить или пропустить. Перекрывать другие приложения и блокировать работу мы не будем.

На iOS такой возможности не существует вовсе; на Android это требует разрешения на показ поверх других приложений либо accessibility-сервиса и привлекает внимание модерации Play; на Windows topmost-окно обходится элементарно. Приложение, которое пытается запереть пользователя, удаляют.

## Considered Options

- Уведомление + полноэкранное окно приложения (выбрано)
- Только уведомление
- Жёсткая блокировка: overlay поверх всех окон, accessibility service, пароль на выход

## Consequences

- На iOS приложение в фоне может только показать локальное уведомление — это не деградация, а предел платформы.
- Экран отдыха должен быть убедительным сам по себе, а не держаться на принуждении.
